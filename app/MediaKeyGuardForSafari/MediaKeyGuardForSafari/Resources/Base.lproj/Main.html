Media Key Guard for Safari

Stops short notification sounds (Teams, Slack, web mail…) from stealing your Mac's play/pause key away from Spotify or Music. Real media — videos, podcasts, live streams — keeps working normally.

You can turn on Media Key Guard for Safari’s extension in Safari Extensions preferences.

Media Key Guard for Safari’s extension is currently on. You can turn it off in Safari Extensions preferences.

Media Key Guard for Safari’s extension is currently off. You can turn it on in Safari Extensions preferences.

Once enabled, allow it on the sites you use (or all websites), then use the toolbar icon to exclude any site you want left alone.
